# Number Guessing Game

## Project Description
This project is a simple Number Guessing Game developed using Java. The computer generates a random number between 1 and 100, and the user has to guess the correct number.

The user gets a maximum of 7 attempts to guess the number.

## Technologies Used
- Java
- Scanner Class
- Random Class
- Exception Handling

## Features
- Generates a random number between 1 and 100.
- Takes input from the user.
- Displays Too High and Too Low hints.
- Allows maximum 7 attempts.
- Displays winning and losing messages.
- Shows the correct number if the user loses.
- Provides a Play Again option.
- Supports multiple rounds.
- Displays the final game summary.
- Handles invalid input.

## How to Run
1. Install Java JDK.
2. Open the project in VS Code or Eclipse.
3. Open `Gamming.java`.
4. Run the program.
5. Enter a number between 1 and 100.
6. Follow the instructions displayed on the screen.
