# Number Guessing Game

## Project Description
This is a simple Number Guessing Game developed using Java. The computer generates a random number between 1 and 100, and the user has to guess the correct number.

The user gets a maximum of 7 attempts to guess the number.

## Technologies Used
- Java
- Scanner Class
- Random Class
- Exception Handling

## Features
- Random number generation between 1 and 100.
- User input using Scanner.
- Too High and Too Low hints.
- Maximum 7 attempts.
- Winning and losing messages.
- Play Again option.
- Multiple rounds.
- Final game summary.
- Invalid input handling.

## How to Run
1. Install Java JDK.
2. Open the project in VS Code.
3. Open `Gamming.java`.
4. Run the program.
5. Enter a number between 1 and 100.
